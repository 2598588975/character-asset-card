# 人物资产卡 · Character Asset Card

通过独立生图、HTML/CSS 排版与原像素拼合，制作人物四视图或复杂分模块角色资产卡。

本技能先分别生成每张视角、表情和细节图，再核对人物与服装的一致性，最后由 HTML/CSS、Canvas 或 Pillow 完成确定性排版与 PNG 导出。完整资产卡与所有采用的独立原图共同保留。

## 两种制作级别

| 级别 | 独立图片 | 适用需求 |
| --- | --- | --- |
| 简单四视图 | 脸部特写、正面、侧面、背面，共四张 | 人物四视图、简单角色资产卡 |
| 复杂分模块 | 正/侧/背、所需表情、服装与配饰细节 | 角色设定卡、表情与造型拆解 |

## 核心约束

- 每个模块独立生成，不把一张多宫格裁成所谓独立原图。
- 将身份参考、发型服装参考与本次有意修改的属性分别写清楚。
- 核对人物自身左右、肩带腕饰、鞋包结构及跨视角一致性。
- HTML/CSS 负责页面网格、文字、编号、色板和留白；响应式显示可缩放。
- 最终 PNG 中每张模块按自然尺寸、整数坐标以 1:1 原生像素放置，不缩放、裁切、调色或重采样。
- 导出后逐模块比较解码像素；浏览器截图、文件大小和“高倍导出”本身不能证明像素保留。
- 完整整卡和每张采用的独立原图放在同一份资产卡文件夹，保留历史版本。

## 安装

下载本仓库，或克隆到新的目录：

```bash
git clone https://github.com/2598588975/character-asset-card.git
```

将仓库文件夹以 `character-asset-card` 为目录名，放入你的 Codex 个人技能目录。目录中应直接包含 `SKILL.md`，其余子目录保持原有相对位置。之后在新会话中调用该技能。

## 调用示例

简单版：

```text
使用 $character-asset-card，为这个人物制作简单四视图。
参考 A 负责身份与肤色，参考 B 负责发型和服装。
分别生成脸部特写、正面、侧面、背面；先核对一致性，
再用 HTML/CSS 排版并以原像素拼合导出 PNG。
保留完整卡与四张采用的独立原图。
```

复杂版：

```text
使用 $character-asset-card，制作复杂分模块角色资产卡。
需要正面、侧面、背面、平静、微笑、服装材质和鞋履细节。
先确认参考分工与页面框架，各模块独立生成，核对后排版。
最终整卡中各图保持原生像素，并提供像素一致性校验记录。
```

## 原像素校验

校验脚本需要 Python 3 与 Pillow：

```bash
python -m pip install Pillow
```

准备一个覆盖全部采用模块的映射 JSON。`source` 相对于映射文件所在目录；尺寸与坐标填写实际整数：

```json
[
  {
    "id": "front",
    "source": "02_正面.png",
    "x": 40,
    "y": 120,
    "width": 1024,
    "height": 1536
  }
]
```

运行：

```bash
python scripts/verify_native_pixels.py 完整资产卡.png 像素区域映射.json --report 像素校验结果.json
```

- 返回 `0`：映射中全部模块的尺寸及 RGBA 解码像素完全一致。
- 返回 `1`：至少一个模块尺寸或像素不一致。
- 非法输入或报告文件已存在时拒绝执行；重新校验应选择新的报告路径。

脚本仅验证映射中列出的模块，不能判断映射是否遗漏图片，也不能验收身份相似度、服装一致性或构图。最终还需实际查看整页 PNG。

详细规则见 [SKILL.md](SKILL.md)，制作与映射示例见 [references/project-examples.md](references/project-examples.md)。
